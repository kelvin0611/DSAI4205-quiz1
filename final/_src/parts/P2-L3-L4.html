二、Spark 核心概念

一分鐘重點
  • RDD = 分散喺好多部機、唔可以改（immutable）嘅數據集合；壞咗靠 lineage 重新計。
  • Transformation（map、filter、flatMap、reduceByKey…）係 lazy，只係記低計劃；Action（collect、count、show、save）先真正執行。
  • 一變一用 map，一變多用 flatMap；加總用 reduceByKey，收集名單用 groupByKey。

Lazy evaluation：transformation 寫計劃，action 先開工

一句講完

Transformation 唔會即刻計，只係喺 memory 起一個 operator DAG；去到 action 先由頭到尾一次過執行。

圖解 點解要 lazy

等齊成個計劃先執行，Spark 可以合併步驟（pipelining）、避免計冇用嘅嘢；而且記低 lineage，有 partition 壞咗就照計劃重新計返嗰份。

易錯

MCQ 問「邊一行先真正執行」：搵第一個 action（collect、count、take、show、saveAsTextFile、write）。

map vs flatMap

一句講完

map：一個 element 變一個；flatMap：一個 element 變零至多個，再攤平成一個 RDD。

圖解
考試點揀

Mutual friends 每個 user 產生好多個 pair、inverted index 每份文件產生好多個 (word, doc)、PageRank 每頁產生好多個貢獻：全部用 flatMap。

reduceByKey vs groupByKey

一句講完

兩個都會按 key shuffle；reduceByKey 喺每個 partition 先合併一次再送，groupByKey 將所有 value 原封不動送過網絡。

四、Hive → Shark → Spark SQL、DataFrame

一分鐘重點
  • Hive 將 SQL 變 MapReduce（慢）；Shark 用 Spark + memory（快）；Spark SQL 加 DataFrame + Catalyst optimizer。
  • DataFrame = 有 schema 嘅分散式 table；schema 用 StructType([StructField(name, type, nullable)])。
  • UDF = 自己寫嘅 Python function：udf(f, ReturnType)，return type 錯就出 null。

DataFrame + UDF 嘅資料流

圖解：Quiz 2 真卷 compliance UDF
df_transactions
id | country | memo
1 | HK | "urgent bitcoin gift"
withColumn + UDF
audit_result =
{risk_score: 80,
flagged_terms: [bitcoin, urgent, gift]}
select + "struct.field"
audit_score = 80
triggered_keywords = [...]
  1. 寫 Python function，回傳值嘅結構要同 schema 一樣（dict key = StructField 名）。
  2. 用 StructType 寫 return type；list 用 ArrayType(StringType())。
  3. udf(function, schema) 註冊。
  4. withColumn("新欄名", my_udf(col("a"), col("b")))，column 次序要跟 function 參數。
  5. 用 col("struct.field").alias("新名") 攤平。

2025s1 Q1(b) · 10 分

用 PySpark RDD 建 inverted index

documents.txt 每行好似 D1 || the cat sat on the mat。輸出 word: [doc ids]，字按字母排，doc id 唔重複。

睇答案
from pyspark.sql import SparkSession
ss = SparkSession.builder.appName("InvertedIndex").master("local[4]").getOrCreate()
spark = ss.sparkContext

lines = spark.textFile("documents.txt")
docs = lines.map(lambda l: l.split("||")) \
            .map(lambda p: (p[0].strip(), p[1].strip().split()))   # (doc_id, [words])

index = docs.flatMap(lambda d: [(w, d[0]) for w in set(d[1])]) \
            .groupByKey() \
            .mapValues(lambda ids: sorted(set(ids))) \
            .sortByKey()

for word, ids in index.collect():
    print(f"{word}: {ids}")
步驟點解
split("||") + strip()分開 doc id 同內容，去走空格
flatMap + set(d[1])一份文件產生好多個 (word, doc)；set 令 D1 嘅兩個 “the” 只出一次
groupByKey()同一個字嘅 doc id 收埋一齊
mapValues(sorted(set()))轉做 list、去重、排序
sortByKey()字按字母排，同 expected output 一樣

都可以用 reduceByKey(lambda a, b: a + b)，map 嗰陣 value 寫 [doc_id]。已用 Python 模擬核對：the → ['D1', 'D3', 'D4']、brown → ['D2', 'D3', 'D4']。

Quiz 2 真卷 Q1(b) · 12 分

Compliance risk UDF：回傳 nested struct 再 flatten

df_transactions 有 transaction_id、account_country、memo_text。Function 回傳 dict：risk_score（含 crypto／bitcoin／mixer +50；urgent／gift／loan 而且國家唔係 US +30；最多 100；memo 空就 −1）同 flagged_terms（搵到嘅字）。

睇答案
from pyspark.sql.functions import udf, col
from pyspark.sql.types import StructType, StructField, StringType, IntegerType, ArrayType

def evaluate_compliance_risk(memo, country):
    if memo is None or str(memo).strip() == "":
        return {"risk_score": -1, "flagged_terms": []}
    memo_lower = str(memo).lower()
    country_upper = str(country).upper() if country else ""
    crypto_terms = {"crypto", "bitcoin", "mixer"}
    urgency_terms = {"urgent", "gift", "loan"}
    found_terms = [t for t in crypto_terms | urgency_terms if t in memo_lower]
    score = 0
    if any(t in memo_lower for t in crypto_terms):
        score += 50
    if any(t in memo_lower for t in urgency_terms) and country_upper != "US":
        score += 30
    score = min(score, 100)
    return {"risk_score": score, "flagged_terms": found_terms}

compliance_schema = StructType([
    StructField("risk_score", IntegerType(), False),
    StructField("flagged_terms", ArrayType(StringType()), False)
])

compliance_udf = udf(evaluate_compliance_risk, compliance_schema)

df_temp = df_transactions.withColumn(
    "audit_result", compliance_udf(col("memo_text"), col("account_country")))

df_audited = df_temp.select(
    col("transaction_id"), col("account_country"), col("memo_text"),
    col("audit_result.risk_score").alias("audit_score"),
    col("audit_result.flagged_terms").alias("triggered_keywords"))
  • Dict 嘅 key 一定要同 StructField 名一樣，否則對唔上，出 null。
  • ArrayType(StringType()) = 裝字串嘅 list。
  • 傳 column 嘅次序要跟 function 參數：先 memo，後 country。
  • 用 "struct.field" 攞出 nested 欄位，再 .alias() 改名。

十、常見疑問

Q：RDD 同 DataFrame 有咩分別？
RDD 係最底層嘅分散式 collection，冇 schema，Spark 睇唔到你 lambda 入面做咩，所以冇得優化。DataFrame 有 schema（column 名同 type），Catalyst optimizer 可以自動優化，通常快啲。
Q：SparkSession 同 SparkContext 點分？
SparkContext（題目通常叫 spark 或者 sc）係 RDD 嘅入口；SparkSession 係 DataFrame／SQL 嘅入口，入面包住一個 SparkContext（ss.sparkContext）。2025s1 卷寫 spark = ss.sparkContext，所以嗰張卷 spark.textFile 係 RDD。
Q：groupByKey 同 reduceByKey 點揀？
要「收集名單」用 groupByKey；要「加總／計數／搵最大」用 reduceByKey，因為佢會先喺每個 partition 合併，shuffle 少好多。
Q：col 係咪改名？
唔係。col("x") 係「揀出 x 呢個 column」；改名用 .alias()；withColumn 第一個參數係新 column 嘅名。
Q：唔識 list comprehension 點算？
用普通 for loop 加 append 一樣得分，例如 mutual friends 嘅雙重 loop。
Q：UDF return type 寫錯會點？
唔會報錯，個 column 會變 null。所以 schema／return type 一定要同實際回傳嘅嘢夾。
