二、筆記：Graph 基本量度

一分鐘重點
  • Graph = node（點）+ edge（線）。無向圖嘅線冇方向，有向圖有箭咀。
  • Degree = 鄰居數；平均 degree \(\langle k\rangle = 2E/N\)；density = 實際 edge ÷ 最多可以有幾多條。
  • Distance = 最短路徑步數；diameter = 所有 distance 入面最大嗰個。
  • Clustering coefficient = 你啲鄰居之間有幾多對都係朋友。

1. 無向圖同有向圖

一句講完

無向圖（undirected）嘅關係係對稱嘅：i 連 j 即係 j 都連 i。有向圖（directed）有方向：A → B 唔代表 B → A。

圖解
易錯

有向圖每個 node 有 in-degree（指入嚟）同 out-degree（指出去）兩個數；距離亦唔對稱，\(d(A,B)\) 可以唔等於 \(d(B,A)\)。

2. Degree 同平均 degree

一句講完

Node i 嘅 degree \(k_i\) = 連住佢嘅 edge 數 = 佢有幾多個鄰居。

$$\langle k \rangle = \frac{1}{N}\sum_i k_i = \frac{2E}{N}$$ 點解係 2E

每條 edge 有兩個端點，數 degree 嗰陣每條 edge 會被兩邊各數一次。所以全部 degree 加埋 = 2E。

圖解（Revision Qs 嘅 graph G） 例子

N = 7，E = 9：\(\langle k\rangle = 2 \times 9 / 7 = 18/7 \approx 2.571\)。

易錯

寫 \(E/N\) 係錯嘅（漏咗 ×2）。可以用「degree 加埋 = 2E」嚟檢查自己有冇數漏 edge。

3. Density：個 graph 有幾密

一句講完

Density = 實際有幾多條 edge ÷ 最多可以有幾多條 edge。

$$\text{Undirected: } \frac{E}{N(N-1)/2} = \frac{\langle k\rangle}{N-1} \qquad\qquad \text{Directed: } \frac{E}{N(N-1)}$$ 點解分母係 \(N(N-1)/2\)

N 個 node 兩兩之間最多連一條線：第一個 node 可以連 N−1 個，第二個再連 N−2 個…… 加埋 \(= N(N-1)/2\)。有向圖每對可以有兩條（A→B 同 B→A），所以唔使除 2。

圖解
例子

Graph G：\(\dfrac{9}{7 \times 6 / 2} = \dfrac{9}{21} \approx 0.429\)。

真實網絡通常好 sparse：MSN 有 1.8 億人，但平均 degree 只係 14.4，density 細到接近 0。

4. Distance、diameter、平均路徑長度

一句講完

Distance \(d(i,j)\) = 由 i 去 j 最短要行幾多條 edge；diameter = 所有 node 對之間 distance 嘅最大值。

$$\text{diameter} = \max_{i,j}\, d(i,j) \qquad\qquad \bar{\ell} = \frac{1}{N(N-1)}\sum_{i \ne j} d(i,j)$$ 有咩用

平均路徑短，資訊傳得快：互聯網傳數據快啲、電網損耗少啲。MSN 平均路徑只係 6.6，即係「六度分隔」嘅 small world。

圖解：graph G 入面最遠嘅一對 例子：搵 diameter 嘅步驟
  1. 搵「最邊」嘅 node（degree 細、喺角落），例如 B、G、A。
  2. 計佢哋之間嘅最短路徑：B→G = 3、A→G = 3（A–C–D–G 或者 A–E–F–G）、A→B = 2。
  3. 確定冇一對大過 3 → diameter = 3。
易錯

Diameter 唔係「最長嘅路徑」（可以兜好多圈），而係「最短路徑入面最長嗰個」。每一對都要用最短行法。

5. Clustering coefficient（CC）：你啲朋友係咪都係朋友

一句講完

Node i 嘅 CC = 佢嘅鄰居之間實際有幾多條 edge ÷ 鄰居之間最多可以有幾多條。

$$C_i = \frac{e_i}{k_i(k_i-1)/2} = \frac{2e_i}{k_i(k_i-1)} \qquad\qquad \bar{C} = \frac{1}{N}\sum_i C_i$$ 點解要咁計

社交網絡入面，「朋友嘅朋友都係朋友」好常見。CC 量度呢個「圍埋一齊」嘅程度：1 = 鄰居全部互相認識，0 = 鄰居之間完全唔認識。MSN 嘅平均 CC 係 0.11。

圖解：計 E 嘅 CC 例子：逐步計
  1. E 嘅鄰居：A、C、F，所以 \(k_E = 3\)。
  2. 鄰居之間最多可以有 \(3 \times 2 / 2 = 3\) 條：A–C、A–F、C–F。
  3. 實際有 A–C、C–F 兩條，\(e_E = 2\)。
  4. \(C_E = 2/3 \approx 0.667\)。
易錯
  • \(e_i\) 只數鄰居同鄰居之間嘅 edge，唔好數連去自己嗰啲。
  • Degree 1 嘅 node 分母 = 0，公式冇定義。Revision Qs 寫明當 1；networkx 預設當 0。考試跟題目假設，冇講就寫明你點假設。

三、Centrality：邊個 node 最重要

一分鐘重點
  • Degree：朋友最多。Closeness：去邊都近。Betweenness：人哋要經你先搵到對方（橋樑）。Eigenvector：你嘅朋友都重要。
  • 兩大類：geometric（睇距離：closeness、harmonic、betweenness）vs connectivity-based／spectral（睇 eigen-structure：eigenvector、Katz）。
  • 唔同 centrality 可以揀出唔同嘅「最重要」node，冇一種係最好。
  • 認圖：最極端（一兩粒好大）= betweenness；最平均 = closeness；中間 = degree。
Centrality問咩問題高分嘅 node
Degree你有幾多朋友？Hub、朋友最多
Closeness你去其他人平均有幾近？喺圖中間
Harmonic同 closeness 一樣，但圖唔連通都用得近又多朋友
Betweenness幾多對人要經過你？橋樑、broker
Eigenvector你嘅朋友重唔重要？連住重要人物

0. Centrality 兩大類（L8 p.31、36、54）

一句講完

Geometric：重要程度係「同其他 node 嘅距離」嘅 function。Connectivity-based（spectral）：重要程度由 graph matrix 嘅 eigen-structure 決定，即係「你鄰居重唔重要」。

分類圖 點記

公式入面有 \(d(x, y)\)（距離）或者最短路徑 ⇒ geometric；公式係 \(c = Ac\)、要 power iteration ⇒ connectivity-based。

易錯

Betweenness 數嘅係「最短路徑經唔經你」，slide 將佢放喺 geometric 下面。MCQ 問「邊個唔係 geometric」，答 eigenvector 或者 Katz。

1. Degree centrality

一句講完

鄰居越多越重要：\(C_{deg}(i) = k_i\)，normalize 就係 \(k_i/(N-1)\)。

幾時唔準

通常夠用（例如電影主角同最多人講嘢），但唔一定：Twitter 最多 contact 嘅帳號往往係 spam；Wikipedia link 最多嘅頁通常係參考列表。

2. Closeness centrality

一句講完

去其他所有 node 嘅距離加埋越細，你就越「中心」。

$$C_{clos}(x) = \frac{1}{\sum_y d(y,x)} \qquad \text{normalised: } \frac{N-1}{\sum_y d(y,x)}$$ 圖解（lecture slide 38） 例子：B 點計
  1. B 去 A = 1、去 C = 1、去 D = 2、去 E = 3。
  2. 加埋 Σd = 7。
  3. \(C_{clos}(B) = 1/7 \approx 0.14\)。
易錯：圖唔連通

有 node 去唔到，\(d = \infty\)，Σd = ∞，所有 node 都變 0。所以先有 harmonic centrality：

$$C_{harm}(x) = \sum_{y \ne x} \frac{1}{d(y,x)}$$

去唔到嘅 node \(1/\infty = 0\)，唔會搞到成條數變 0。例：鄰居 1 個、距離 2 嘅 2 個、距離 3、4 各 1 個：\(1 + \tfrac12 \times 2 + \tfrac13 + \tfrac14 \approx 2.58\)。

3. Betweenness centrality

一句講完

數吓有幾多對 node 之間嘅最短路徑要經過你。

$$C_{bet}(v) = \sum_{s \ne v \ne t} \frac{\sigma_{st}(v)}{\sigma_{st}}$$

\(\sigma_{st}\) = s 同 t 之間有幾多條最短路徑；\(\sigma_{st}(v)\) = 其中幾多條經 v。無向圖每對只計一次。

有咩用

量度「broker」角色：兩群人之間要經你傳訊息，你一走，網絡就斷開（single point of failure）。呢種 node 嘅 degree 可以好低。

圖解：diamond（lecture slide 49） 例子：逐對數 C 嘅 betweenness
Pair最短路徑經 C？C 得分
A–EA-B-C-E、A-B-D-E（2 條）1 條經 C0.5
B–EB-C-E、B-D-E（2 條）1 條經 C0.5
其他對—唔經 C0
合計1

快捷：star（中間連住 n 個 leaf）中心 = \(n(n-1)/2\)，例如 5 個 leaf = 10。

Slide 例子 (a)：Path A–B–C–D–E（L8 p.47）
  • B：A 去 C、D、E 都要經 B ⇒ 3 對（A–C、A–D、A–E）。
  • C：左邊 {A, B} 去右邊 {D, E} 都要經 C ⇒ 2 × 2 = 4 對。
  • A、E 喺尾，冇人要經佢哋 ⇒ 0。
Slide 例子 (b)：兩個三角形 + 中間一粒（bow-tie，L8 p.48）
  • d：左邊 {a, b, c} 去右邊 {e, f, g} 全部要經 d ⇒ 3 × 3 = 9。
  • c：{a, b} 去 {d, e, f, g} 全部要經 c ⇒ 2 × 4 = 8。e 一樣 = 8。
  • a、b：三角形入面 a–b 直接連住，冇人要經佢哋 ⇒ 0。
快捷計法如果拎走 v 之後個 graph 斷開做兩邊，大細係 m 同 n，而且所有跨邊嘅最短路徑都要經 v（冇第二條路），咁 v 嘅 betweenness 至少係 \(m \times n\)。Path 嘅 C = 2 × 2、bow-tie 嘅 d = 3 × 3、c = 2 × 4 都係咁計。
易錯

有幾條一樣短嘅路徑時要攤分（partial credit）；唔好當成全部經你。

4. Eigenvector centrality

一句講完

你嘅分數 = 你鄰居分數加埋。連住重要人物，你都重要。

$$c \leftarrow A\,c, \qquad c \leftarrow \frac{c}{\lVert c \rVert_2}$$ 例子

A–B、A–C、A–D、C–D，由 \(c^{(0)} = [1,1,1,1]\) 開始：A = B+C+D = 3、B = A = 1、C = A+D = 2、D = A+C = 2；除 \(\sqrt{18}\) 得 [0.707, 0.236, 0.471, 0.471]。繼續 iterate 收斂去 [0.612, 0.282, 0.523, 0.523]。PageRank 同 Katz 都係佢嘅變種。

Slide algorithm（L8 p.59）
  1. \(c^{(0)} = [1, 1, \dots, 1]\)。
  2. \(c^{(k)} = A\,c^{(k-1)}\)：每粒 node 嘅新分數 = 鄰居舊分數加埋。
  3. \(c^{(k)} = c^{(k)} / \lVert c^{(k)} \rVert_2\)：除 L2 norm（\(\sqrt{\text{平方和}}\)），唔係除總和。
  4. 如果 \(\lVert c^{(k)} - c^{(k-1)} \rVert > \varepsilon\)，返去 Step 2；否則停。

六、MCQ

七、短答題

S1. 點解有時 low-degree 嘅 node 都好重要？畫圖說明。（2026s2 Q5c，3 分）

參考答案

如果佢係連接兩個群組嘅橋樑（bridge／broker），兩邊之間嘅所有最短路徑都經佢，所以 betweenness 好高；佢一失效網絡就分開（single point of failure）。圖：兩個三角形中間由一個 degree 2 嘅 node 連住（見上面 past paper 答案嘅圖）。

S2. Closeness 同 harmonic 有咩分別？

參考答案

Closeness = 1/Σd（或者 (N−1)/Σd），只喺 connected graph 有意義；有 node 去唔到，d = ∞，全部變 0。Harmonic = Σ1/d，去唔到嘅貢獻 0，所以唔連通嘅圖都用得；同 closeness 高度相關，但會偏向 degree 大嘅 node。

八、常見疑問

Q：Geometric 同 connectivity-based 點分？
公式有距離／最短路徑 ⇒ geometric（closeness、harmonic、betweenness）；要 \(c = Ac\) power iteration ⇒ connectivity-based（eigenvector、Katz，PageRank 係變種）。
Q：Eigenvector 每步除 L2 norm 定除總和？
跟 slide 除 L2 norm（√平方和）。最後 slide 再將所有數除 node 1，寫成 [1, 1.41, 1.27, 0.52, 1]，方便比較。
Q：Betweenness 要唔要 normalize？
過去題目只問「邊個最高」，用原始數比較就得。要 normalize 嘅話，無向圖除以 \((N-1)(N-2)/2\)。
Q：Betweenness 計 (s,t) 同 (t,s) 兩次？
無向圖每對計一次（lecture 嘅 star 例子 5×4/2 = 10 就係咁）。
Q：Closeness 用 1/Σd 定 (N−1)/Σd？

Q：CC 嘅 e 包唔包連去自己嗰啲 edge？
唔包，只數鄰居同鄰居之間嘅 edge。
Q：Density 有向圖同無向圖點分？
無向圖分母 \(N(N-1)/2\)，有向圖分母 \(N(N-1)\)。題目冇講就睇 graph 有冇箭咀。
Q：Diameter 同平均路徑長度點分？
Diameter 係所有最短路徑之中最長嗰個；平均路徑長度係所有最短路徑嘅平均。
Q：認圖嗰題點樣唔撈亂？
先搵最極端（betweenness），再搵最平均（closeness），剩低係 degree，最後按題目要求次序寫。
