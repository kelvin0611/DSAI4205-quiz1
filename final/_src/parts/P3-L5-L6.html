BPE segmenter：用學到嘅 merge rules 切新句子

一句講完

BPE 有兩部分：learner（由 corpus 學 merge rules，上面嗰個流程）同 segmenter／encoder（將新句子切成 token）。Segmenter 嘅做法係：先拆做單字母，再按學到嘅次序逐條 merge rule 喺成句度 apply 一次。

點解要跟次序

後面嘅 rule 係由前面嘅 rule 砌出嚟（例如 fred_ = fr + ed_，而 ed_ = e + d_）。唔跟次序，ed_ 都未出現，fred_ 就砌唔到。唔係揀最長嗰個 token。

例子：L5 p.20

Training corpus “fred fed ted bread, and ted fed fred bread”（空格寫做 _）。學到嘅 vocabulary（slide 編號 1–13）：

Merge rules 次序：① d + _ → d_ ② e + d_ → ed_ ③ f + r → fr ④ fr + ed_ → fred_。新句子：“ted and fred are friends”。

  1. 拆字母：t e d _ a n d _ f r e d _ a r e _ f r i e n d s
  2. Rule ① d_：t e d_ a n d_ f r e d_ a r e _ f r i e n d s（friends 尾嗰個 d 後面係 s，唔合併）
  3. Rule ② ed_：t ed_ a n d_ f r ed_ a r e _ f r i e n d s（and 嘅 d_ 前面係 n，唔係 e）
  4. Rule ③ fr：t ed_ a n d_ fr ed_ a r e _ fr i e n d s
  5. Rule ④ fred_：t ed_ a n d_ fred_ a r e _ fr i e n d s
  6. 轉 token id：8 11 1 6 10 13 1 7 4 9 12 ? 4 6 3 ?（i 同 s 唔喺 vocabulary，出 ?）

  • 句尾 “friends” 後面冇空格，所以冇 _。
  • Slide 嘅 vocabulary 寫 ‘fred’，但由 fr + ed_ 合併出嚟，其實係 fred_（帶空格）。

一句講完

Stemmer 照規則剪字尾，唔識文法；lemmatizer 查字典（WordNet）攞返原形，但要俾佢知個字係咩詞性（POS）。

  • Porter：規則只識剪 -ing、-s 呢類，不規則動詞（gave、given）搞唔掂。
  • Lancaster：剪得更狠，連 give 都變 giv；gave 變 gav，仍然同其他唔一樣。
  • WordNet lemmatizer（俾咗 wordnet.VERB）：四個全部變 give。
點解 lemmatize 要俾 POS

lemmatize(word) 唔俾 pos 就當 noun：“lives” → “life”。T5 notebook 嘅做法係先 nltk.pos_tag，tag 入面有 v（動詞）就 lemmatize(word, pos='v')（“lives” VBZ → “live”），否則 pos='n'。

Porter 規則嘅 m 條件（Exam Review p.77）

規則 (m > 1) EMENT → （刪走）：m = 字幹入面 VC（元音 + 輔音）出現幾多次。

  • replacement → 字幹 “replac” = r·e·pl·a·c，有 2 個 VC，m = 2 > 1 ⇒ 刪 ement ⇒ replac。
  • cement → 字幹 “c”，m = 0 ⇒ 條件唔成立 ⇒ 保持 cement。
易錯

Stem 唔一定係真字（replac、giv）；lemma 一定係字典入面嘅字。

Vector space 熱身：D1、D2 邊個似 Q？（L5 p.56）

\(D_1 = 2T_1 + 3T_2 + 5T_3\)、\(D_2 = 3T_1 + 7T_2 + T_3\)、\(Q = 0T_1 + 0T_2 + 2T_3\)。

\(D_1 \cdot Q = 2\cdot0 + 3\cdot0 + 5\cdot2 = 10\)，\(\lVert D_1\rVert = \sqrt{38} = 6.164\)，\(\lVert Q\rVert = 2\)：

$$\cos(D_1, Q) = \frac{10}{6.164 \times 2} = 0.81$$

\(D_2 \cdot Q = 1\cdot2 = 2\)，\(\lVert D_2\rVert = \sqrt{59} = 7.681\)：

$$\cos(D_2, Q) = \frac{2}{7.681 \times 2} = 0.13$$

⇒ D1 似 Q 好多：Q 只有 T3，D1 嘅 T3 份量最重。（numpy 核對）

易錯

D2 個 vector 長過 D1，但長度唔重要；cosine 睇嘅係方向（角度）。

三、TF-IDF + user profile + cosine（log₂ 版）

2025s1 Q4（20 分）係成份卷最多分嘅單一題目之一，套路係：① stop words + lowercase ② 計 df、IDF ③ 每套戲嘅 TF-IDF vector ④ 用 rating 計 user profile ⑤ profile 同每套戲計 cosine，揀最高。

公式（2025s1 formula sheet）

TF

字 i 喺文件 j 出現幾多次；題目冇講就用 raw count：

$$tf_{ij} = f_{ij} \quad\text{or}\quad \frac{f_{ij}}{\max_i f_{ij}} \quad\text{or}\quad \frac{f_{ij}}{|d_j|}$$ IDF

N = 文件數，\(df_i\) = 有幾多份文件有字 i：

$$idf_i = \log_2\!\left(\frac{N+1}{df_i+1}\right) + 1$$ TF-IDF $$w_{ij} = tf_{ij} \cdot idf_i$$ User profile

\(w_m\) = user 俾戲 m 嘅 rating − 平均 rating（正數 = 鍾意）：

$$\text{profile} = \frac{\sum_m w_m \cdot \text{TFIDF}_m}{\sum_m |w_m|}$$ Cosine $$\cos(A,B) = \frac{A \cdot B}{\lVert A\rVert\,\lVert B\rVert}$$ 流程圖
① Stop words + lowercase
② 數 df，計 IDF
③ 每份文件 TF × IDF → vector
④ 用 rating 加權 → profile
⑤ profile 同每套戲 cosine，揀最高

完整示範

Movie 1：“Tony's tech and genius are incredible”（user rating 4，平均 3.5）。Movie 2：“His genius and tech are amazing”（rating 5，平均 3）。原卷第三套戲冇印出嚟，所以加一套未睇嘅 Movie 3：“His tech is amazing and incredible”，問 user 會唔會鍾意。

睇逐步答案

① Stop words + lowercase：刪 and、are、his、is。

  • M1：tony's, tech, genius, incredible
  • M2：genius, tech, amazing
  • M3：tech, amazing, incredible

② df 同 IDF（N = 3，所以 (N+1) = 4）

tony's1log₂2 + 1 = 2
tech3log₂1 + 1 = 1
genius2log₂(4/3) + 1 = 1.415
incredible21.415

計數機log₂x = log x / log 2。log₂(4/3) = 0.1249 / 0.3010 = 0.415。

③ TF-IDF vector（次序：tony's, tech, genius, incredible, amazing；每個字出現一次，TF = 1）

M1 = [2, 1, 1.415, 1.415, 0    ]   ‖M1‖ = 3.001
M2 = [0, 1, 1.415, 0,     1.415]   ‖M2‖ = 2.237
M3 = [0, 1, 0,     1.415, 1.415]   ‖M3‖ = 2.237

④ User profile：w₁ = 4 − 3.5 = 0.5，w₂ = 5 − 3 = 2。

profile = (0.5·M1 + 2·M2) / (0.5 + 2)
        = [1+0, 0.5+2, 0.7075+2.83, 0.7075+0, 0+2.83] / 2.5
        = [0.4, 1, 1.415, 0.283, 1.132]     ‖profile‖ = 2.127

⑤ Cosine

profile·M3 = 0 + 1 + 0 + 0.283×1.415 + 1.132×1.415 = 3.002
cos(profile, M3) = 3.002 / (2.127 × 2.237) = 0.631
cos(profile, M1) = 0.659
cos(profile, M2) = 0.968

Profile 最似 M2（user 最鍾意嗰套）；未睇嘅 M3 cosine = 0.631（已用 numpy 核對）。如果要推介，就揀未睇過嘅戲入面 cosine 最高嗰套。

四、RDD 手計 TF-IDF（T5 TODO 0、1.1、1.2）

T5 老師揀咗呢題做 tutorial，同 TF-IDF 長題同類，而且 code 嘅 TF／DF 寫法同 T4 汽車例子逐行一樣，考 fill-in 好可能就係呢幾行。Operator 本身點用（mapValues、flatMapValues、countByKey、countByValue）喺 P2 operator 表。

一分鐘重點
  • 公式：raw TF × \(\ln\frac{n+1}{df+1}\)（PySpark 版，自然 log）；n = 文件數（code 叫 num_of_documents）。
  • TF 模板：flatMapValues(lambda x: x).countByValue() → key 係 (doc, word)。
  • DF 模板：flatMapValues(lambda x: x).distinct().map(lambda x: (x[1], x[0])).countByKey()，distinct 去走同一份文件嘅重複字。
  • countByValue／countByKey 係 action，返回 Python dict，唔係 RDD；所以 TF-IDF 要 join 嗰陣，老師改用 reduceByKey 同 mapValues 整 RDD。

Levenshtein DP：每格睇三個鄰居（兩個擺法並排）

一句講完

每格 = 「將 source 嘅某個前綴變成 target 嘅某個前綴，最少要幾多步」。每格都係由三個鄰居揀最細，再加今次嗰步：

$$D[\text{格}] = \min\begin{cases} D[\nwarrow] + c & \text{對角}\\ D[\uparrow] + 1 & \text{上面}\\ D[\leftarrow] + 1 & \text{左邊}\end{cases}$$ $$c = \begin{cases}0 & \text{match}\\ 1 & \text{substitute}\end{cases}$$

數字點計兩個擺法都一樣，連最後個距離都一樣。唯一唔同嘅係：↑ 同 ← 邊個叫 insert、邊個叫 delete。題目要你寫 traceback 操作名嘅時候先會影響分數。

圖解：兩個擺法並排
擺法 A（老師 slides、L6 code）擺法 B（Quiz 2 真卷）
寫喺左邊（rows）targetsource
寫喺頂（columns）sourcetarget
↑ 由上面嚟 +1insert（加一個 target 字母）delete（刪一個 source 字母）
← 由左邊嚟 +1delete（刪一個 source 字母）insert（加一個 target 字母）
↖ 對角match（+0）／substitute（+1）：兩個擺法一樣
點解會調轉？一條通用規則

唔使死記兩套。記一句：沿住 source 條軸行一格 = 用走一個 source 字母、冇砌到 target = delete；沿住 target 條軸行一格 = 砌多一個 target 字母 = insert。

  • 擺法 A：source 寫喺頂（橫排），由左邊格向右行一格（←）= 用走一個 source 字母 = delete；target 寫喺左（直排），由上面格向下行一格（↑）= insert。
  • 擺法 B：source 寫喺左，所以 ↑ = delete；target 寫喺頂，所以 ← = insert。
考試時點樣由題目字眼判斷（4 步）
  1. 搵 source 同 target：“transform X into Y”、“from X to Y”、“convert X to Y” ⇒ X = source，Y = target。題目直接寫 Source Word／Target Word 就跟佢。

諗 subproblem 嘅方法

淨係諗最後一個字母點處理：substitute／match 就兩邊都剪走最尾（對角格）；delete 就只剪 source；insert 就只剪 target。剩低嗰部分就係 table 已經計好嘅細題目，再加今次嗰步嘅 0 或 1。

$$J(A,B) = \frac{\lVert A \cap B \rVert}{\lVert A \cup B \rVert} = \frac{2}{6} = 0.33$$ $$\text{Jaccard distance} = 1 - J = 0.67$$

六、L6 Word embedding

一分鐘重點
  • Word embedding = 每個字一個 dense 低維向量，意思近嘅字向量近。
  • T06 notebook 係 CBOW：(1000, 8) → Embedding (1000, 8, 25) → mean (1000, 25) → softmax (1000, V)。
  • Skip-gram：center 估 context；CBOW：context 估 center。Hidden layer node 數 = d，output = V。
  • SGNS 將 softmax 變二元分類（1 正例 + k 負例），快好多；兩個 model 都用 NLL 做 loss。

Notebook 用 context 字估 center 字，存做 cbow.csv，所以係 CBOW（唔係 skip-gram）。

w = 4                                   # 每邊 4 個字 ⇒ window = 9 個字（出界補 PAD）
def windows_to_batch(batch_windows):
    w = batch_windows.shape[1] // 2     # 9 // 2 = 4
    X, Y = [], []
    for window in batch_windows:
        X.append(np.concatenate((window[:w], window[w+1:])))   # 前 4 + 後 4 = 8 個 context id
        Y.append(window[w])                                    # 中間嗰個 = center
    Y = ku.to_categorical(Y, vocab_size)                       # center 變 one-hot
    return np.array(X), Y

model = Sequential()
model.add(Embedding(input_dim=vocab_size, output_dim=25))
model.add(Lambda(lambda x: tf.reduce_mean(x, axis=1), output_shape=(25,)))
model.add(Dense(vocab_size, activation="softmax"))

  • axis=1 收埋嘅係「8 個 context」嗰維，唔係 batch（axis 0）亦唔係 dim（axis 2）。

NLL 同 SGNS（2026s2 Q4b、c）

概念重點
點解用 Negative Log-LikelihoodSkip-gram 同 CBOW 都係俾每個字一個機率（softmax）。訓練目標係令真實 context／center 字嘅機率最大。將所有機率相乘再取 log，相乘變相加（數值穩定、易微分）；加負號將「最大化 likelihood」變成「最小化 loss」，可以用 gradient descent。
SGNS 目的完整 softmax 每步要計成個 vocabulary（幾十萬字），好慢。SGNS 將問題變成二元分類：真 context 字（正例）vs k 個隨機抽嘅字（負例），每步只更新 k+1 個字嘅 vector，快好多，效果仍然好。
Word2Vec 嘅限制一個字一個固定 vector（一字多義撈埋一齊）；只睇 context，反義詞（increased／decreased）會好似；冇見過嘅字（OOV）冇 vector → 用 subword（BPE、FastText）。

十一、常見疑問

Q：TF 同 df 有咩分別？
TF 數一個字喺一份文件入面出現幾多次；df 數有幾多份文件有呢個字，每份最多計 1。同一份文件有兩個 big，TF = 2，但 df 只加 1。
Q：IDF 點解要 +1（分子分母）？
避免 df = 0 時除以 0（smoothing）。2025s1 版最尾再 +1，令所有文件都有嘅字 IDF = 1 而唔係 0。
Q：Levenshtein 嘅 subproblem 點嚟？
淨係諗最後一個字母點處理：substitute／match 就兩邊都剪走最尾（對角格）；insert 就只剪 target（insert 方向嗰格）；delete 就只剪 source。剩低嗰部分就係細啲嘅題目，table 已經計咗。
Q：Stemming 同 lemmatization 考試點分？
Stemming 照規則剪（Porter／Lancaster），出嚟可以唔係真字，唔識不規則動詞；lemmatization 查 WordNet，要俾 POS（唔俾當 noun）。見 give／gave 對比。
Q：T06 係 skip-gram 定 CBOW？
CBOW：X = 8 個 context，Y = center（one-hot）。見 CBOW 卡。
Q：↑ 係 insert 定 delete？我成日搞亂。
先搵 source 喺邊條軸。沿 source 軸行一格 = delete，沿 target 軸行一格 = insert。老師擺法（target 放 row）：↑ = insert、← = delete。Quiz 2 真卷（source 放 row）：↑ = delete、← = insert。距離數字兩個擺法都一樣。
Q：BPE segmenter 係咪揀最長嘅 token？
唔係。由單字母開始，按 learner 學到 merge rule 嘅次序逐條 apply。見 BPE segmenter。
Q：countByValue 同 countByKey 邊個計 TF、邊個計 DF？
TF：flatMapValues → countByValue（數 (doc, word)）。DF：flatMapValues → distinct → (word, doc) → countByKey。見 RDD 手計 TF-IDF。
Q：CBOW hidden layer 有幾多個 node？
等於 embedding dimension d，同 vocabulary 大細 V、window m 都無關。Output layer 先係 V 個 node。
Q：Skip-gram 數 pair 要唔要計 PAD？
題目話用 PAD 就計；兩個答案（含 PAD／唔含 PAD）都寫出嚟最穩陣。
Q：BPE 打和點揀？
次數一樣嘅 pair 揀邊個都得，但要寫明你揀咗邊個，同埋最後 token 數一定要啱。
