每次嘅題目都係同一個套路，只係換 graph。跟住下面五步做，就唔會漏分：

  1. 數 out-degree：每頁有幾多條箭咀射出去，寫喺 node 旁邊。
  2. 砌 matrix M：column = 由邊頁出發，row = 去邊頁，每格填 \(1/d_i\)。檢查每個 column 加埋 = 1。
  3. 寫每頁嘅 equation：由 M 嘅每一個 row 讀出嚟，再加 teleport \((1-\beta)/N\)。
  4. 計 iteration 1、2：iteration 1 用 \(r^{(0)} = 1/N\)；iteration 2 用 iteration 1 嘅結果。每次都檢查總和 = 1。
  5. 排序：由大到細，打和寫等號。

二、筆記：由零講起

一分鐘重點
  • PageRank 將 link 當成投票：多啲重要嘅頁 link 你，你就重要。
  • 每頁將自己嘅分數平均分俾佢 link 去嘅頁：\(r_j = \sum_{i \to j} r_i / d_i\)。
  • 寫成 matrix：\(r = M r\)。M 嘅 column = from，row = to。用 power iteration 一路乘 M 直到唔變。
  • 兩大問題：dead end（冇 out-link，分數漏走）同 spider trap（入得去出唔返，吸晒分數）。
  • 解決：random teleport，每步有 \(1-\beta\) 機率隨機跳：\(r_j = \sum \beta\, r_i/d_i + (1-\beta)/N\)。

1. Web 係一個 graph：link 就係投票

一句講完

網頁係 node，hyperlink 係有方向嘅 edge（箭咀）。一頁被越多重要嘅頁 link，就越重要。

點解要咁做

搜尋「IBM」會有成千上萬頁 match 到隻字：IBM 官網、Wikipedia、spam 頁……單靠內容分唔到邊頁可信。但係人哋願唔願意 link 你，就反映咗你有幾可信。所以 Google 用 link 結構嚟排名。

  • 睇 in-link（人哋 link 你），唔係 out-link。Out-link 係你自己寫嘅，好易作弊。
  • 唔係每票一樣重：重要嘅頁投嘅票更重；而且一頁 link 得越多頁，每票就越輕（佢嘅分數要攤分）。
圖解 易錯

「in-link 多就一定排第一」係錯嘅。PageRank 睇嘅係 link 你嗰啲頁有幾重要、佢哋 link 咗幾多頁，唔係單純數 link。

2. Flow formulation：每頁將分數平均分出去

一句講完

頁 j 嘅分數 = 所有 link 去 j 嘅頁，各自將分數平均分出嚟、分俾 j 嗰份加埋。

$$r_j = \sum_{i \to j} \frac{r_i}{d_i}$$

\(r_i\) 係頁 i 嘅分數，\(d_i\) 係頁 i 嘅 out-degree（射出幾多條箭咀）。

點解要除 \(d_i\)

想像每頁手上有一定數量嘅「水」（分數），佢會平均倒落每條 out-link。i 有 3 條 out-link，每條就分到 \(r_i/3\)。咁樣全部水嘅總量唔會變（加埋永遠 = 1），只係喺頁之間流動。所以叫 flow（流量）formulation。

圖解：y、a、m 三頁 例子：逐步解方程

由圖逐頁寫「邊個流入嚟」：

$$\begin{aligned} r_y &= \tfrac{r_y}{2} + \tfrac{r_a}{2} \\ r_a &= \tfrac{r_y}{2} + r_m \\ r_m &= \tfrac{r_a}{2} \end{aligned}$$

三條方程其實得兩條係獨立嘅（任何答案乘一個數都仲啱），所以要加多一條：

$$r_y + r_a + r_m = 1$$
  1. 由第三條：\(r_a = 2 r_m\)。
  2. 代入第一條：\(r_y/2 = r_a/2\)，即 \(r_y = r_a = 2r_m\)。
  3. 代入總和：\(2r_m + 2r_m + r_m = 5r_m = 1\)，所以 \(r_m = 1/5\)。
  4. 答案：\(r_y = 2/5,\ r_a = 2/5,\ r_m = 1/5\)。
易錯

Gaussian elimination 只適合細 graph。真正嘅 web 有幾十億頁，解方程要 \(O(N^3)\)，冇可能，所以實際上用下面嘅 power iteration。考試計數題都係用 iteration。

3. Stochastic adjacency matrix M

一句講完

將 flow 方程寫成 matrix：\(r = M\,r\)。M 嘅每一格係「由 column 嗰頁流去 row 嗰頁嘅比例」。

$$M_{ji} = \begin{cases} \dfrac{1}{d_i} & \text{if } i \to j \\[4pt] 0 & \text{otherwise} \end{cases}$$ 點解 column 係 from

咁樣 \(M r\) 第 j 行就係 \(\sum_i M_{ji} r_i\)：把所有頁流去 j 嘅份量加埋，正正就係 flow 方程。每頁將自己嘅分數全部分晒出去，所以每個 column 加埋 = 1，呢個叫 column stochastic。

圖解：由 graph 填 matrix
to ＼ fromyam
y½½0
a½01
m0½0
Σ111

橙色 column = y 嘅分數點樣分：一半留俾自己，一半俾 a。

填表步驟
  1. 揀一頁，例如 y，數佢嘅 out-degree：\(d_y = 2\)。
  2. 喺 y 嗰個 column，佢指去嘅每一頁（y、a）嗰行填 \(1/2\)，其他填 0。
  3. 每頁都做一次，填晒成個表。
  4. 檢查每個 column 加埋 = 1。唔係 1 就一定填錯（dead end 嗰個 column 係 0，下面會講）。
易錯

最常見錯誤係將 row 當 from，成個 matrix 轉置咗，之後全部計錯。記法：「由 column 行落 row」。寫完一定要做 column 加總檢查。

4. Power iteration：一路乘 M 直到唔變

一句講完

由每頁分數一樣（1/N）開始，不斷計 \(r \leftarrow M r\)，直到分數唔再變，就係 PageRank。

流程圖 例子：y、a、m（冇 teleport）
頁r⁽⁰⁾r⁽¹⁾r⁽²⁾r⁽³⁾…最後
y1/31/35/123/82/5
a1/31/21/311/242/5
m1/31/61/41/61/5

以 \(r^{(1)}\) 為例：\(r_y = \tfrac12 \cdot \tfrac13 + \tfrac12 \cdot \tfrac13 = \tfrac13\)；\(r_a = \tfrac12 \cdot \tfrac13 + 1 \cdot \tfrac13 = \tfrac12\)；\(r_m = \tfrac12 \cdot \tfrac13 = \tfrac16\)。最後收斂去 2/5、2/5、1/5，同解方程一樣。

Random walk 解釋

想像有個 random surfer：每一步喺而家呢頁隨機揀一條 out-link 撳落去。\(r_j\) 就係「行咗好耐之後，佢喺頁 j 嘅機率」。行到夠耐，機率分佈唔再變，呢個叫 stationary distribution。所以 PageRank 一定加埋 = 1。

6. 解決方法：random teleport

一句講完

Random surfer 每一步：機率 \(\beta\) 跟 link 行，機率 \(1-\beta\) 隨機跳去任何一頁。

$$r_j = \sum_{i \to j} \beta\,\frac{r_i}{d_i} + \frac{1-\beta}{N}$$

\(\beta\) 通常 0.8 至 0.9，考試用 0.8。所以每頁每次都有一份「保底」\((1-\beta)/N\)。

圖解 點解解決到兩個問題
問題Teleport 點幫
Spider trap數學上冇錯，但答案唔係我哋想要。有 teleport，surfer 每步都有 \(1-\beta\) 機率跳走，幾步之內就會離開個 trap，trap 唔會吸晒分數。
Dead end係數學問題：M 唔係 column stochastic。規定去到 dead end 就一定 teleport，即係將嗰個 column 改成全部 \(1/N\)，咁 M 就重新 column stochastic。

Google matrix

$$A = \beta M + (1-\beta)\left[\frac{1}{N}\right]_{N\times N}, \qquad r = A\,r$$ 例子（lecture slide 41）

y → y, a；a → y, m；m → m（spider trap），\(\beta = 0.8\)，N = 3。每格 = \(0.8 \times M_{ji} + 0.2 \times \tfrac13\)：

yam
y0.8·½ + 0.2·⅓ = 7/157/151/15
a7/151/151/15
m1/157/150.8·1 + 0.2·⅓ = 13/15

Power iteration：[⅓, ⅓, ⅓] → [0.33, 0.20, 0.47] → [0.28, 0.20, 0.52] → … → [7/33, 5/33, 21/33]。m 仍然最高（佢始終係 trap），但 y、a 唔再變 0。

易錯
  • Teleport 項係 \((1-\beta)/N\)，唔係 \(\beta/N\)，亦唔係 \(1-\beta\)。β = 0.8、N = 4 就係 0.05；N = 5 就係 0.04。
  • 題目叫「stochastic adjacency matrix」只要 M（冇 teleport）；叫「Google matrix」先要寫 A。

7. 大型 graph 點計：sparse formulation

一句講完

唔好砌 Google matrix A，只用 sparse 嘅 M 計，再將漏咗嘅分數平均補返。

點解

A 每一格都唔係 0（每格都有 teleport 份），N = 10 億頁就要 \(10^{18}\) 格，冇可能放落 memory。M 只係記住 link，好 sparse。

$$r' = \beta M r, \qquad S = \sum_j r'_j, \qquad r_j^{\text{new}} = r'_j + \frac{1-S}{N}$$

冇 dead end 時 \(1 - S = 1 - \beta\)，即係同直接加 \((1-\beta)/N\) 一樣；有 dead end 就漏多啲，用 \(1-S\) 一次過補返。

8. MapReduce 版本

一句講完

每個 iteration 係一個 MapReduce job：Map 將每頁分數分俾 out-link，Reduce 將收到嘅加埋再加 teleport。

圖解（lecture slide 49：A → B,C,D；B → A,D；C → A；D → B,C；每頁初始 1/4）

Map(key = page, value = PR(page)):

Reduce(key = page, values = contributions):
    emit(page, β · sum(values) + (1 − β) / N)

五、PySpark PageRank code（2025s1 Q3c，10 分）

要求：用 adjacency list RDD (node, [out-neighbours])，只用 RDD transformation（map、flatMap、join、reduceByKey），唔用 DataFrame 或者 matrix。

from pyspark.sql import SparkSession
from operator import add

ss = SparkSession.builder.appName("Spark PageRank").master("local[4]").getOrCreate()
spark = ss.sparkContext

links = spark.parallelize([
    ("1", ["2", "4", "5"]),
    ("2", ["3", "5"]),
    ("3", ["5"]),
    ("4", ["2", "3"]),
    ("5", ["2"]),
]).cache()

N = links.count()
beta = 0.8
ranks = links.mapValues(lambda _: 1.0 / N)          # r(0) = 1/N

for i in range(2):
    # 每頁將 rank 平均分俾 out-neighbours
    contribs = links.join(ranks).flatMap(
        lambda x: [(dst, x[1][1] / len(x[1][0])) for dst in x[1][0]])
    # 冇 in-link 嘅頁都要保留（貢獻 0）
    contribs = contribs.union(links.mapValues(lambda _: 0.0))
    ranks = contribs.reduceByKey(add) \
                    .mapValues(lambda s: beta * s + (1 - beta) / N)

for page, r in sorted(ranks.collect()):
    print(page, round(r, 4))
步驟做咩
links.join(ranks)每頁變成 (page, ([neighbours], rank))
flatMap每頁產生好多個 (dst, rank/d)，所以用 flatMap
union(... 0.0)頁 1 冇 in-link，唔補 0 嘅話 reduceByKey 之後會消失
reduceByKey(add)將每頁收到嘅貢獻加埋（Σ r_i/d_i）
mapValues(β·s + (1−β)/N)加 teleport

輸出：1 0.04、2 0.3547、3 0.2107、4 0.0507、5 0.344，同人手計一樣（已用 Python 模擬 RDD 運算核對）。

六、MCQ

七、短答題

S1. 用一句講 dead end 同 spider trap，各畀一個例子，再講解決方法。（2026s2 Q3a，8 分）

參考答案
  • Dead end：頁冇 out-link，random surfer 去到冇路行，importance 漏走。例子：A → B，B 冇任何 link。
  • Spider trap：一組頁嘅 out-link 全部指返組入面，最後吸晒所有 importance。例子：C → C，C 自己 link 自己。
  • 解決：random teleport。每步以 β 機率跟 link，1 − β 機率隨機跳去任何一頁：r_j = Σ β r_i/d_i + (1 − β)/N。Spider trap 幾步內跳得出；dead end 就一定 teleport（column 改做 1/N），令 M 重新 column stochastic。

S2. 點解 PageRank 唔直接數 in-link 數目？

參考答案

因為唔係每個 link 一樣有份量：重要頁嘅 link 應該更重；而且淨係數 in-link 好易被 spam 頁互相 link 嚟作弊。PageRank 用遞歸定義，rank 由 link 你嗰啲頁嘅 rank 決定，再按佢哋嘅 out-degree 攤分。

S3. 解釋點解 power iteration 適合大型 web graph。

參考答案

Gaussian elimination 要 O(N³)，N 係十億級做唔到。Power iteration 每步只係一次 sparse matrix 乘 vector（只同 link 數成正比），可以用 MapReduce／Spark 平行計，通常 50 次左右就收斂。

八、常見疑問

Q：考試要寫 matrix 定寫每頁 equation？
2025s1、2026s2 都要求先寫 stochastic matrix；舊 COMP4434 卷要求寫 equation。最穩陣兩樣都寫：matrix 一個表，然後由每個 row 寫 equation 再代數。
Q：row 同 column 點分？
Column = from，row = to。睇 A 嗰個 column，就係 A 將分數分俾邊個。寫完檢查每個 column 加埋係咪 1。
Q：teleport 嗰項係 (1−β)/N 定 (1−β)？
\((1-\beta)/N\)。Teleport 係平均跳去 N 頁之一，所以要除 N。β = 0.8、N = 4 就係 0.05。
Q：Iteration 2 用咩數？
用 iteration 1 嘅結果，唔係 1/N。每一步都係用「上一步嘅 r」。
Q：有 dead end 嘅題目點做？
將 dead end 嗰個 column 改成全部 1/N（一定 teleport），然後照常計。寫明你做咗呢個處理先攞到分。
Q：兩頁分數一樣，排序點寫？
寫等號，例如 A > B = C = D，講明打和。
Q：題目話「Stochastic Adjacent matrix」要唔要加 teleport？
唔使。佢就係 M（每格 \(1/d_i\)）。Teleport 喺計 iteration 先加。
Q：小數要留幾多位？
至少 4 位，或者用分數。過程唔好太早四捨五入，否則總和唔係 1。
Q：Random surfer 同 PageRank 有咩關係？
PageRank 就係 random surfer 長遠停喺每頁嘅機率。所以全部頁加埋一定 = 1，可以用嚟檢查計數。
