Subword tokenization（BPE）

點解要：解決 unknown word（OOV）。例如訓練數據有 “foot” 同 “ball” 但冇 “football”，或者有 low、new、newer 但冇 lower。Subword 可以減細 vocabulary，靈感來自 information theory 嘅數據壓縮。

三個演算法做咩
Token learner由 training corpus 學 vocabulary：① 全部拆成單字母 ② 搵最常出現嘅相鄰 pair ③ 合併並加入 vocabulary（大小 +1）④ 重複直至夠數或者冇 pair 再夠頻率
Token segmenter（encoder）用學到嘅 vocabulary（同 merge 次序）切新句子
Token merger（decoder）將 token 序列砌返原本句子

Lecture 例子：(“hug”,10), (“pug”,5), (“pun”,12), (“bun”,4), (“hugs”,5) → 先合併 u g → ug（20 次），再 u n → un（16 次），再 h ug → hug（15 次）。GPT 類 tokenizer 將空格變成特別字元 Ġ，放喺字頭。

三、TF-IDF + user profile + cosine（log₂ 版）

2025s1 Q4（20 分）係成份卷最多分嘅單一題目之一，套路係：① stop words + lowercase ② 計 df、IDF ③ 每套戲嘅 TF-IDF vector ④ 用 rating 計 user profile ⑤ profile 同每套戲計 cosine，揀最高。

公式（2025s1 formula sheet）

TF

字 i 喺文件 j 出現幾多次；題目冇講就用 raw count：

$$tf_{ij} = f_{ij} \quad\text{or}\quad \frac{f_{ij}}{\max_i f_{ij}} \quad\text{or}\quad \frac{f_{ij}}{|d_j|}$$
IDF

N = 文件數，\(df_i\) = 有幾多份文件有字 i：

$$idf_i = \log_2\!\left(\frac{N+1}{df_i+1}\right) + 1$$
TF-IDF
$$w_{ij} = tf_{ij} \cdot idf_i$$
User profile

\(w_m\) = user 俾戲 m 嘅 rating − 平均 rating（正數 = 鍾意）：

$$\text{profile} = \frac{\sum_m w_m \cdot \text{TFIDF}_m}{\sum_m |w_m|}$$
Cosine
$$\cos(A,B) = \frac{A \cdot B}{\lVert A\rVert\,\lVert B\rVert}$$
流程圖
① Stop words + lowercase
② 數 df，計 IDF
③ 每份文件 TF × IDF → vector
④ 用 rating 加權 → profile
⑤ profile 同每套戲 cosine，揀最高

完整示範

Movie 1：“Tony's tech and genius are incredible”（user rating 4，平均 3.5）。Movie 2：“His genius and tech are amazing”（rating 5，平均 3）。原卷第三套戲冇印出嚟，所以加一套未睇嘅 Movie 3：“His tech is amazing and incredible”，問 user 會唔會鍾意。

Levenshtein DP：每格睇三個鄰居

一句講完

\(D[i][j]\) = 將 source 頭 i 個字母變成 target 頭 j 個字母最少要幾多步。

$$D[i][j] = \min\begin{cases} D[i-1][j-1] + \begin{cases}0 & x_i = y_j\\ 1 & x_i \ne y_j\end{cases} & \text{match／substitute} \\ D[i-1][j] + 1 & \text{delete } x_i \\ D[i][j-1] + 1 & \text{insert } y_j \end{cases}$$
圖解（source 放 row、target 放 column） 諗 subproblem 嘅方法

淨係諗最後一個字母點處理：substitute／match 就兩邊都剪走最尾（對角格）；delete 就只剪 source；insert 就只剪 target。剩低嗰部分就係 table 已經計好嘅細題目，再加今次嗰步嘅 0 或 1。

Levenshtein 擺法提醒考試題目會講明邊個字串放 row、邊個放 column。Rows 係 source（X）嘅話：↑ 上面 = delete X 嘅字母，← 左邊 = insert Y 嘅字母，↖ 對角 = match／substitute。擺法調轉，insert 同 delete 就調轉。開始之前喺表旁邊寫低呢三行。

五、L6 Word embedding

一分鐘重點
  • Word embedding = 每個字一個 dense 低維向量，意思近嘅字向量近。
  • Skip-gram：center 估 context；CBOW：context 估 center。Hidden layer node 數 = d，output = V。
  • SGNS 將 softmax 變二元分類（1 正例 + k 負例），快好多；兩個 model 都用 NLL 做 loss。

字嘅意思

  • Lemma：break, breaks, broke, broken, breaking 共用 lemma “break”
  • Synonymy：couch／sofa、car／automobile（完全同義好少）
  • Similarity vs relatedness：couch／sofa 相似；couch／pillow 只係有關聯
  • Antonymy：只喺一個特徵相反：long／short、rise／fall

Semantic feature space

  • 用特徵（cuteness、size；gender、age、royalty）表示字，用 Euclidean distance 比較
  • Analogy：king − man + woman：[1,8,8] − [1,7,0] + [9,7,0] = [9,8,8] ≈ queen
  • 手動設計特徵唔可行 → 由大量文字自動學，typical 300 維
  • Distributional hypothesis：喺相似上下文出現嘅字意思相似。Harris（1954）：oculist 同 eye-doctor 出現喺差唔多嘅環境；Firth（1957）：“You shall know a word by the company it keeps.”
  • One-hot 嘅問題：cat 同 feline 嘅 one-hot cosine = 0，捉唔到相似。Embedding 將每個字變成 continuous dense vector，意思近嘅字喺空間入面距離近。

Skip-gram vs CBOW（Word2Vec, Mikolov 2013）

Skip-gramCBOW
Input → OutputCenter word → 每個 context word所有 context words → center word
假設① 每個 window 係 i.i.d. 樣本 ② 俾定 center，context words 條件獨立 ③ 唔理 context 位置（前 1 位、後 2 位一樣處理）① window i.i.d. ② 每個 context word 用同一方法處理，唔理位置
LossJ(θ) = −Σₜ Σ₋ₘ≤ⱼ≤ₘ, ⱼ≠0 log P(wₜ₊ⱼ | wₜ)（negative log likelihood）J(θ) = −Σₜ log P(wₜ | wₜ₋ₘ, …, wₜ₊ₘ)
模型P(o|c) = exp(u_o·v_c) / Σₖ exp(u_k·v_c)（softmax）用 (1/2m)(v_o1 + … + v_o2m) 平均再同 u_c 做 dot product + softmax
每個字兩個向量用 center 向量 V 做 embedding；context 向量 U 只喺訓練用通常用 context 向量做 embedding
T06 Keras 實作—Embedding(vocab, dim) → Lambda(mean) → Dense(vocab, softmax)，loss = categorical cross-entropy，optimizer = Adam；PAD = index 0、UNK = 1

Lecture 數字例子：one-hot × W 等於揀出 W 嘅某一行（lookup table），例如 “passes” → v_c = [0.1, 0.2, 0.7]；乘 W′ 得 logits，softmax 後 loss = −log(0.155065) = 0.8095。CBOW example：W 兩行 (0.38, 0.42) 同 (−0.11, 0.1) 取平均 → h = (0.135, 0.26)，softmax 後 P(sit) = 0.2626，loss = −log(0.2626)。

SGNS 同 GloVe

Skip-gram with Negative Sampling

  • 問題：softmax 分母要加總成個 vocabulary V（可以好大），好慢
  • 做法：變成 binary logistic regression：(center, 真 context) → y = 1；(center, 隨機抽嘅字) → y = 0
  • P(y=1|c,o) = σ(u_o·v_c) = 1/(1+e^(−u_o·v_c))
  • 點解要 negative：淨係有 positive，模型只要將 dot product 調到好大就「作弊」令 loss 變細
  • 每個 positive 抽 k 個 negative：J = −log σ(u_o·v_c) − Σ log(1 − σ(u_k·v_c))

GloVe（Stanford）

  • Global Vectors：先建 co-occurrence count matrix（V × V，好高維）
  • 用 matrix factorization 分解成低維 embedding
  • 好處：好快；捉到 word2vec（只睇 batch 入面嘅 window）睇唔到嘅 global statistics
  • 但一般 word2vec 效果較好

NLL 同 SGNS（2026s2 Q4b、c）

概念重點
點解用 Negative Log-LikelihoodSkip-gram 同 CBOW 都係俾每個字一個機率（softmax）。訓練目標係令真實 context／center 字嘅機率最大。將所有機率相乘再取 log，相乘變相加（數值穩定、易微分）；加負號將「最大化 likelihood」變成「最小化 loss」，可以用 gradient descent。
SGNS 目的完整 softmax 每步要計成個 vocabulary（幾十萬字），好慢。SGNS 將問題變成二元分類：真 context 字（正例）vs k 個隨機抽嘅字（負例），每步只更新 k+1 個字嘅 vector，快好多，效果仍然好。
Word2Vec 嘅限制一個字一個固定 vector（一字多義撈埋一齊）；只睇 context，反義詞（increased／decreased）會好似；冇見過嘅字（OOV）冇 vector → 用 subword（BPE、FastText）。

九、短答題

4. 點解要 subword tokenization？

Word-level models cannot handle unknown (out-of-vocabulary) words, e.g. “football” when only “foot” and “ball” were seen, and a word vocabulary becomes huge with many rare words. Subword methods such as BPE build a vocabulary of frequent character sequences by repeatedly merging the most frequent adjacent pair, so any new word can be represented as a sequence of known subwords while keeping the vocabulary small.

5. Stemming 同 lemmatization 有咩分別？

Stemming crudely chops affixes with rules (e.g. Porter's), and the result may not be a real word (computing → comput, companies → compani). Lemmatization uses vocabulary and part-of-speech information to return the dictionary form (am, are, is → be; ran → run), which is more accurate but slower.

6. Skip-gram 同 CBOW 有咩分別？

Skip-gram uses the centre word to predict each context word in the window; CBOW uses the (averaged) context words to predict the centre word. Both assume windows are independent samples and ignore the position of context words. Skip-gram uses the centre-word vectors as embeddings; CBOW commonly uses the context vectors.

7. 點解要 negative sampling？

The softmax in standard skip-gram normalizes over the whole vocabulary V, which is very expensive when V is large. SGNS turns the task into binary logistic regression with a sigmoid: real (centre, context) pairs are labelled 1 and k randomly sampled words are labelled 0. Negative samples are needed because with only positive pairs the model could trivially make every dot product large.

8. GloVe 同 Word2Vec 有咩分別？

Word2Vec learns from local context windows. GloVe first builds a global word–word co-occurrence count matrix (V × V) over the whole corpus and factorizes it into low-dimensional vectors, so it is fast and captures global statistics that window-based word2vec misses, although word2vec often works better in practice.

11. (5 marks) Explain the out-of-vocabulary (OOV) problem and how Byte Pair Encoding addresses it, with an example.

Word-level models only have vectors for words seen in training, so a new word such as “football” (when only “foot” and “ball” were seen) is unknown. BPE starts from single characters and repeatedly merges the most frequent adjacent pair into a new token, building a vocabulary of frequent subwords. A new word is then segmented into known subwords, e.g. “pineapple” → p, i, n, e, apple, so every word can be represented while the vocabulary stays small.

十、常見疑問

Q：TF 同 df 有咩分別？
TF 數一個字喺一份文件入面出現幾多次；df 數有幾多份文件有呢個字，每份最多計 1。同一份文件有兩個 big，TF = 2，但 df 只加 1。
Q：IDF 點解要 +1（分子分母）？
避免 df = 0 時除以 0（smoothing）。2025s1 版最尾再 +1，令所有文件都有嘅字 IDF = 1 而唔係 0。
Q：Levenshtein 嘅 subproblem 點嚟？
淨係諗最後一個字母點處理：substitute／match 就兩邊都剪走最尾（對角格）；insert 就只剪 target（insert 方向嗰格）；delete 就只剪 source。剩低嗰部分就係細啲嘅題目，table 已經計咗。
Q：CBOW hidden layer 有幾多個 node？
等於 embedding dimension d，同 vocabulary 大細 V、window m 都無關。Output layer 先係 V 個 node。
Q：Skip-gram 數 pair 要唔要計 PAD？
題目話用 PAD 就計；兩個答案（含 PAD／唔含 PAD）都寫出嚟最穩陣。
Q：BPE 打和點揀？
次數一樣嘅 pair 揀邊個都得，但要寫明你揀咗邊個，同埋最後 token 數一定要啱。
