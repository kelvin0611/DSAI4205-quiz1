function map(student, courses):          # input: (student, list of courses)
    courses = sort(courses)
    for i in 0 .. len(courses)-1:
        for j in i+1 .. len(courses)-1:
            emit((courses[i], courses[j]), student)   # output: ((c1, c2), student)

function reduce(pair, students):          # input: ((c1, c2), [students])
    emit(pair, list(students))            # output: ((c1, c2), list)

def to_pairs(record):

B2 · Filter + count（14 分）

每個城市有幾多張「Electronics 而且金額 > 1000」嘅訂單

大 table 分散喺好多個 file，每行 (order_id, city, category, amount)。例子：(1, HK, Electronics, 1200)、(2, HK, Books, 1500)、(3, Tokyo, Electronics, 900)、(4, HK, Electronics, 3000)、(5, Tokyo, Electronics, 1800)、(6, Seoul, Electronics, 1001)、(7, Seoul, Toys, 2000)。(a) Map、Reduce pseudocode。(b) PySpark 完整 code（file 叫 orders.csv，用逗號分隔）。

睇答案

直覺：兩個條件都喺 Map 度檢查，唔符合就唔 emit；符合就 emit (city, 1)，Reduce 加總。

function MAP(key = line offset, value = "id, city, category, amount"):
    id, city, category, amount = parse(value)
    if category == "Electronics" and amount > 1000:
        emit(city, 1)                     # output: (city, 1)

function REDUCE(key = city, values = [1, 1, ...]):
    emit(city, sum(values))               # output: (city, count)
from pyspark.sql import SparkSession
from operator import add
ss = SparkSession.builder.appName("Orders").master("local[4]").getOrCreate()
spark = ss.sparkContext

rows = spark.textFile("orders.csv").map(lambda l: l.split(","))
counts = rows.filter(lambda r: r[2].strip() == "Electronics" and float(r[3]) > 1000) \
             .map(lambda r: (r[1].strip(), 1)) \
             .reduceByKey(add)
for city, n in sorted(counts.collect()):
    print(city, n)

輸出：HK 2、Seoul 1、Tokyo 1（已用 Python 核對）。訂單 3 只得 900，唔計；訂單 6 係 1001，計。

易錯「> 1000」唔包 1000 本身；amount 讀入嚟係字串，要 float() 或者 int() 先比較。
B3 · Inverted index 變化（16 分）

記埋每份文件出現幾多次

D1：big data big model；D2：data model；D3：big graph data data。輸出 word: [(doc, count), ...]，按字母排。(a) Pseudocode。(b) RDD code（documents.txt 每行 D1 || big data big model）。

睇答案

直覺：同普通 inverted index 一樣按字 group，但 value 要帶埋次數。Mapper 可以先喺自己份文件數好（Counter），再 emit (word, (doc, count))。

function MAP(doc_id, text):
    counts = count each word in text
    for each (word, c) in counts:
        emit(word, (doc_id, c))          # output: (word, (doc, count))

function REDUCE(word, postings):         # input: (word, [(doc, count), ...])
    emit(word, sort(postings by doc_id))
from collections import Counter
lines = spark.textFile("documents.txt")
docs = lines.map(lambda l: l.split("||")) \
            .map(lambda p: (p[0].strip(), p[1].strip().split()))
index = docs.flatMap(lambda d: [(w, (d[0], c)) for w, c in Counter(d[1]).items()]) \
            .groupByKey() \
            .mapValues(lambda ps: sorted(ps)) \
            .sortByKey()
for w, ps in index.collect():
    print(f"{w}: {ps}")
word輸出
big[(D1, 2), (D3, 1)]
data[(D1, 1), (D2, 1), (D3, 2)]
graph[(D3, 1)]
model[(D1, 1), (D2, 1)]

C3 · 有向圖（8 分）

A → B、B → C、C → A、C → D、D → E

(a) Density。(b) d(A, E) 同 d(E, A)。(c) 係咪 strongly connected？(d) 點解呢個圖用 closeness 唔好，要用 harmonic？

睇答案
  • (a) 有向圖：\(\dfrac{E}{N(N-1)} = \dfrac{5}{5 \times 4} = 0.25\)。
  • (b) \(d(A,E) = 4\)（A → B → C → D → E）；\(d(E,A) = \infty\)，因為 E 冇 out-link。Distance 唔對稱。
  • (c) 唔係。只有 {A, B, C} 係互相去得到嘅（一個 strongly connected component），D、E 各自自成一組。
  • (d) 有啲 node 之間 distance = ∞，closeness \(1/\sum d\) 會變 0，冇得比較。Harmonic \(\sum 1/d\) 將 ∞ 當 0 貢獻，照樣計到。

E、常見疑問

Q：Dead end 嗰個 column 要唔要乘 β？
要。改咗 column 之後當普通 column 用：\(\beta \times \tfrac1N\) 再加 teleport。所以 A2 入面 E 貢獻係 \(0.8 \times r_E/5\)。
Q：Spider trap 題目要唔要改 M？
唔使。M 照 link 寫，teleport 已經解決問題；只有 dead end 先要改 column。
Q：Combinatorial pair 題點樣快速檢查答案？
每個 record 有 n 個項目，就會產生 \(n(n-1)/2\) 個 pair。B1：3 + 1 + 3 + 1 = 8 個 pair，shuffle 之後名單總長度都應該係 8。
Q：Filter 放 Map 定 Reduce？
放 Map。唔符合嘅記錄唔 emit，shuffle 少好多數據。
Q：Betweenness 有冇捷徑？
如果某個 node 係兩群之間唯一嘅橋，betweenness = 左邊 node 數 × 右邊 node 數（再加埋佢自己做端點以外嘅其他經過佢嘅對）。C2 嘅 D：3 × 4 = 12。
